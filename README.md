# Prakash Kumar S — Property & Company Valuation

Portfolio website of **Prakash Kumar S**, civil engineer and valuer with 5+ years of experience valuing residential, commercial and industrial property and land for NBFC lending and private clients.

🔗 **Live site:** [https://tejasprof84.github.io/prakash-valuation/](https://tejasprof84.github.io/prakash-valuation/)

## About

Prakash provides property and company valuation services across **Bangalore, Mangalore, Mysore, Mandya and Hassan**. The site presents his profile, services, valuation process and track record, and lets clients send an enquiry directly.

## Services

- **Property Valuation** — residential, commercial, industrial, land & building
- **Company Valuation** — DCF and residual method
- **Estimation & Due Diligence** — for home loans and loan against property (LAP)

## Website Features

- Interactive 3D site view (Three.js) — drag to orbit, tap a building to see how it gets valued
- Sections: Profile, Services, Process, Record, Engage
- Live IST clock and light/dark mode toggle
- Enquiry form powered by Formspree
- Responsive layout for mobile and desktop

## Tech Stack

- HTML, CSS, JavaScript (single `index.html`)
- [Three.js](https://threejs.org/) r128 for the 3D scene
- [Formspree](https://formspree.io/) for form submissions
- Hosted on GitHub Pages

## Run Locally
